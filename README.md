## 🛠️ Tecnologías Utilizadas
- **HTML5 & CSS3 semántico**
- **Bootstrap 5.3 (vía CDN):** Sistema de grillas responsivo, utilidades y componentes.
- **Bootstrap Icons:** Iconografía vectorial integrada.
- **JavaScript (Vanilla):** Manejo dinámico de interacción en UI.
- **Git & GitHub Pages:** Control de versiones y alojamiento estático continuo.

---

## 📋 Estructura y Secciones
El portafolio cuenta con las siguientes secciones optimizadas para dispositivos móviles, tablets y pantallas de escritorio:
1. **Información personal:** Presentación general y enlaces directos de contacto.
2. **Estudios realizados:** Formación de pregrado en Ingeniería Informática y participación en semilleros.
3. **Proyectos:** Descripción de proyectos e iniciativas técnicas.
4. **Tecnologías y lenguajes:** Stack técnico dominado en backend, frontend, bases de datos y sistemas.
5. **Áreas de interés profesional:** Ciberseguridad, sistemas operativos, computación en la nube (AWS) y sistemas embebidos.
